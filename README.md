**Приложение для избавления от вредных привычек и формирования полезных.**

**Стек технологий:**
- UI: Compose
- Архитектура: MVVM + Clean Architecture (Presentation / Domain / Data)
- База данных: Room
- Асинхронность: Coroutines + Flow
- DI: Koin
- Навигация: (Navigation Component)

**Фичи**
- Рабочий календарь
- Создание/Редактирование списка привычек
- Добавление привычек на выбранный день
- Статистика всех привычек за определенный месяц
- Визуальное выделение текущего дня
